# Багровая Сеть: Живой Патруль

Мобильная браузерная idle/clicker-игра версии 1.0.0.

## Играть

https://sergeevvlas186-web.github.io/crimson-web-patrol/

## Что обновлено

- шесть героев и восемь уникальных районных злодеев;
- читаемые имена прямо на карточках выбора персонажей;
- отдельные палитры, свет и движения для каждого случайного вторжения;
- тактические модули закреплены над прокручиваемым путём уровней;
- многослойные живые 3D-фигуры с глубиной, перспективой, бликами и реакцией на указатель;
- полная замена героя злодеем во время событий и босс-боя;
- увеличенные и выровненные иконки, вкладки и нижняя навигация;
- удалённый гардероб и новые награды Осколками за освобождение районов;
- более плавная стоимость развития, награды, опыт и повторные бои;
- изящный генеративный саундтрек с мягкими аккордами и пространственным эхом;
- адаптивный интерфейс, Яндекс SDK, облачная миграция V19 → V20 и офлайн-прогресс до 6 часов.

Откройте `index.html` для основной версии или `phone.html` для мобильного входа.
