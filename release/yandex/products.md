# Товары для Payments API

Идентификаторы в консоли должны полностью совпадать с кодом игры.

| ID | Название | Описание | Рекомендуемый ценовой уровень |
|---|---|---|---|
| `shards_80` | 80 осколков | Небольшой набор осколков | начальный |
| `shards_250` | 250 осколков | Выгодный набор осколков | средний |
| `shards_700` | 700 осколков | Большой набор осколков | высокий |
| `founder_pack` | Набор основателя | Стартовый премиальный комплект | средний |
| `umbra_character` | Герой Умбра | Разблокировка персонажа Умбра | средний |
| `void_web_fx` | Эффект Пустотной сети | Косметический эффект интерфейса | начальный |
| `music_pack_night` | Музыка Ночной дозор | Дополнительный музыкальный набор | начальный |

Если товары не созданы, соответствующие кнопки остаются недоступными. Это предотвращает оплату несуществующего продукта.
