# Чек-лист релиза 1.0.0

## Готово в сборке

- [x] Один `index.html` в корне ZIP
- [x] SDK подключается через относительный `/sdk.js`
- [x] `LoadingAPI.ready()` вызывается после загрузки игры и сохранения
- [x] `GameplayAPI.start()` и `GameplayAPI.stop()` синхронизированы с игрой
- [x] Поддержаны `game_api_pause`, `game_api_resume` и сворачивание страницы
- [x] Гостевая игра доступна без обязательной авторизации
- [x] Локальный прогресс сохраняется; для авторизованного игрока используется Player.setData
- [x] Реклама с наградой вызывается только по кнопке и явно сообщает награду
- [x] На время рекламы приостанавливаются геймплей и звук
- [x] Покупки используют только Payments API Яндекс Игр
- [x] Язык портала определяется через `ysdk.environment.i18n.lang`
- [x] Выделение текста и системное контекстное меню отключены в игровом интерфейсе
- [x] Интерфейс адаптирован для мобильного и компьютерного экранов
- [x] Все имена файлов в сборке без пробелов и кириллицы
- [x] Нет внешних рекламных SDK, аналитики или платёжных ссылок

## Перед загрузкой в консоль

- [ ] Указать рабочий email разработчика
- [ ] Загрузить `icon-512.png`, `cover-800x470.png` и `hero-1560x520.png`
- [ ] Загрузить минимум два реальных скриншота для каждой выбранной платформы
- [ ] Создать товары с идентификаторами из `products.md`, если монетизация покупками включается в первой версии
- [ ] Включить признак облачных сохранений
- [ ] Оставить включённой отложенную публикацию после прохождения модерации
- [ ] Проверить черновик на мобильном устройстве и компьютере
- [ ] После проверки владельцем отдельно отправить игру на модерацию

## Проверка поведения

- [ ] Новый гость начинает с чистого прогресса
- [ ] Перезагрузка страницы восстанавливает прогресс
- [ ] Вход через Яндекс ID не сбрасывает локальный прогресс
- [ ] Звук прекращается при сворачивании и возвращается после фокуса
- [ ] Реклама не открывается повторно во время активного показа
- [ ] Награда начисляется только после `onRewarded`
- [ ] Покупка начисляется один раз и затем подтверждается
- [ ] Имена видны при выборе каждого героя
- [ ] Во время вторжения герой полностью заменяется злодеем
- [ ] Суперспособность доступна поверх панели уровней
- [ ] Персонажи не перекрывают нижнюю навигацию
